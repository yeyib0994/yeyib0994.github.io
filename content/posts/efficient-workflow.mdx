好的工具配置能显著降低日常开发的摩擦力。这里分享我目前在 macOS 上使用的一套配置。

## Shell：Zsh

启用历史补全与别名，配合 `fzf` 实现模糊搜索历史命令：

```bash
# ~/.zshrc
setopt SHARE_HISTORY
setopt HIST_IGNORE_DUPS
alias gs="git status"
alias ll="ls -lah"
```

## 编辑器：模块化配置

无论使用 VS Code 还是 Neovim，原则都是：

1. 快捷键肌肉记忆要一致
2. 插件按需加载，避免启动慢
3. 主题低对比度但层次分明

## Git 小技巧

设置全局的 `lg` 别名，用图形化方式查看提交历史：

```bash
git config --global alias.lg "log --oneline --graph --decorate --all"
```

工具是为思考服务的。配置再花哨，如果分散了注意力，就该做减法。
